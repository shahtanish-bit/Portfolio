# My Portfolio — tanish-sha.vercel.app

heyy, this is a portfolio of a 14 year old who wanted to actually understand what goes into making a real website. No templates, no builders — just HTML, CSS, and JavaScript.

---

## What's in it

- A home page with a terminal animation that types out a JS object about me (I am genuinely so proud of this one, it took wayy longer than it should have)
- A background video with a black hole visual on the hero (mix-blend-mode: lighten is insane for this)
- A sticky navbar, kinda with liquid glass effect that drops down on scroll on mobile into a sidebar
- An experience page going through my projects with actual context about what I built and why (i'm 14 so it will have more projectss soon 😛)
- A contact page

## Things I learned building this

Fixing the mobile zoom bug that was breaking the whole layout was probably the most painful thing. Turns out a single meta viewport line was missing. Spent like a weekend on that.

The typing animation in the terminal block was the most fun to build. It renders HTML-aware characters one by one without breaking the span tags. Writing that logic without a library was something completely new for me.

Responsive CSS is genuinely frustrating. That part of the code is the messiest and I'm not pretending otherwise. Still it taught me why most websites look absolutely banger on desktops but look average on mobiles

## How to run it locally

I mean idk why u'd want to run it locally, but if u like my portfolio and want to use it as a template, just clone it and open `index.html` in a browser. No build step, no `npm install`, nothing.

```bash
git clone https://github.com/shahtanish-bit/main-portfolio
cd main-portfolio
# open index.html in your browser
```
